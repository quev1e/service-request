# Система обработки заявок общежития

## Описание проекта

Веб-приложение для организации процесса подачи и обработки заявок на устранение неисправностей и решение бытовых проблем в общежитии.

Система позволяет проживающим создавать заявки и отслеживать ход их выполнения, специалистам — принимать заявки в работу и изменять их статус, а администраторам — управлять учётными записями пользователей.

Проект разработан с использованием фреймворка Django.

## Основные возможности

- Регистрация и авторизация пользователей.
- Разграничение доступа в зависимости от роли пользователя.
- Создание, просмотр, редактирование и удаление заявок.
- Прикрепление изображений и видео к заявкам и комментариям.
- Просмотр подробной информации о заявках.
- Назначение заявок специалистам.
- Изменение статусов заявок.
- Добавление комментариев и ответов на них.
- Редактирование и удаление комментариев.
- Управление учётными записями пользователей.
- Фильтрация заявок по категориям и другим параметрам.

## Роли пользователей

В системе предусмотрено три роли.

### Проживающий (Resident)

- Создаёт заявки на устранение неисправностей.
- Просматривает список собственных заявок.
- Просматривает подробную информацию о своих заявках.
- Редактирует и удаляет свои заявки.
- Добавляет комментарии и вложения.
- Отслеживает изменение статуса заявки.

### Специалист (Specialist)

- Просматривает заявки, относящиеся к назначенным ему категориям.
- Принимает заявки в работу.
- Изменяет статус назначенных ему заявок.
- Просматривает подробную информацию о заявках.
- Добавляет комментарии и вложения.

### Администратор (Administrator)

- Просматривает заявки.
- Просматривает список пользователей и информацию об отдельных пользователях.
- Создаёт учётные записи проживающих, специалистов и других администраторов.
- Редактирует данные пользователей.

## Технологии

- **Python** — основной язык программирования.
- **Django** — веб-фреймворк.
- **Django ORM** — взаимодействие с базой данных.
- **HTML и CSS** — создание пользовательского интерфейса.
- **SQLite** — база данных (если используется стандартная конфигурация проекта).

## Структура проекта

Основные приложения проекта:

- `users` — управление пользователями, их ролями и профилями, регистрация и редактирование учётных записей.
- `requests` — работа с заявками, категориями, комментариями и вложениями.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/quev1e/service-request.git
```

Перейдите в каталог проекта:

```bash
cd service-request
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация виртуального окружения:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

Если в проекте присутствует файл `requirements.txt`, выполните:

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание администратора

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000/
